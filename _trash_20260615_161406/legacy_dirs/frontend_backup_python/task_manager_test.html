✅ Task Manager - Drag & Drop Functionality

How it works:

  • Users can drag tasks between any columns (To Do → In Progress → Review → Done)
  • Drag and drop works - just grab a task card and drop it in another column
  • Admin can mark tasks incomplete - when a task is in "Done", click "Mark Incomplete" button
  • Flagged tasks - tasks marked incomplete get a 🚩 FLAGGED badge and red border
  • Same as existing task managers - works like Trello, Jira, etc.

Features:

  • ✅ Drag and drop between all columns
  • ✅ Mark incomplete button (only shows in Done column)
  • ✅ Flagged tasks highlighted with red border
  • ✅ Delete tasks
  • ✅ Create new tasks
  • ✅ Priority levels (Low, Medium, High, Urgent)
