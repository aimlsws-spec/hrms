┌─────────────────────────────────────────────────────────────────────┐
│ DASHBOARD FEATURES                                                   │
└─────────────────────────────────────────────────────────────────────┘

  1. CREATE SALARY
     • Select employee
     • Enter Annual CTC
     • Choose template (Standard/Executive)
     • Auto-calculates all components
     
  2. PENDING APPROVALS
     • View pending salary structures
     • Approve/reject structures
     • Track approval history
     
  3. PROCESS PAYROLL
     • Select month/year
     • Create payroll run
     • Process all active salaries
     • View processing summary
     
  4. SALARY CALCULATOR
     • Quick CTC breakdown
     • Test different templates
     • Preview before creating

┌─────────────────────────────────────────────────────────────────────┐
│ WORKFLOW EXAMPLE                                                     │
└─────────────────────────────────────────────────────────────────────┘

  New Employee Salary Setup:
  
  1. Login as accountant
  2. Go to "Create Salary" tab
  3. Select employee: "John Doe"
  4. Enter CTC: 600000
  5. Choose: "Standard Template"
  6. Click "Create & Calculate"
  7. Review breakdown
  8. Structure created (pending status)
  9. Approve when ready
  10. Activate on joining date

  Monthly Payroll:
  
  1. Go to "Process Payroll" tab
  2. Select month: "2024-12"
  3. Click "Create Payroll Run"
  4. System processes all active salaries
  5. View summary (employees, total amount)
  6. Salary slips auto-generated

┌─────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                      │
└─────────────────────────────────────────────────────────────────────┘

  Problem: Cannot login
  Fix: Run python init_accountant.py
  
  Problem: Wrong dashboard
  Fix: Clear browser cache, login again
  
  Problem: Employee not found
  Fix: Check /api/employees/all
  
  Problem: Calculation error
  Fix: Verify CTC and template
